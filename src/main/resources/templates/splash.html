About Us

Hotel De Soleil is a hotel reservation system designed to make room booking easier, faster, and more organized. Users can create an account, book available rooms, view their bookings, and send feedback to the hotel.

For the admin side, the system helps manage room availability, booking records, guest information, and user feedback.
